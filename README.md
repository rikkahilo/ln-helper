# 轻小说助手（Chrome 扩展）

面向轻小说在线阅读场景的浏览器扩展（Manifest V3）。功能涵盖：多站点正文与插图抓取、本地统一书库缓存、EPUB / PDF 导出、内置阅读器、AI 翻译与 AI 辅助处理、OCR 图文识别，以及本地 txt / epub / mobi 导入。

内核来自同一作者先前的油猴脚本 `轻小说下载·阅读·翻译（ESJ Zone / 哔哩轻小说）` v4.9.167，移植为扩展形态，详见文末「来源与许可」。

> **使用前请务必阅读[免责声明](#免责声明)。** 本项目仅提供本地化的网页抓取与阅读工具，不提供、不存储、不传播任何作品内容。

## 一、功能

### 1. 抓取与缓存

- **整本抓取**：解析站点目录 → 章节列表 → 逐章正文与插图。
- **抓取方式**
  - `增量抓取`：仅补抓尚未缓存或有更新的章节。
  - `全部重抓`：重新抓取整本书。
  - `选章抓取`：自选章节抓取；已缓存章节默认不勾选，勾选即重新抓取；章节带 `已缓存` 徽标。
  - `抓取本章`：仅抓取当前所在章节。
- **特殊章节标记**：`密码` 徽标。密码章正文经字体加密混淆（或需在站点页面输入密码解锁），无法自动抓取，支持手动替换正文。
- **抓取失败兜底**：失败章节单独记录，可在缓存管理中重新抓取；导出时若存在缓存副本会自动回退。
- **抓取方式设置**：可选择「用后台标签页抓取」，默认关闭（即静默抓取）；两种方式请求节奏一致。
- **防盗链图片**：自动记录图床 Referer 白名单（上限 50 条，遇到新图床自动追加），可一键清空。
- **图片去重**：同一图片 URL 在书内共享复用，避免重复占用空间。

### 2. 导出

- **导出格式**：`EPUB`、`PDF(浏览器打印另存)`。
- **两种导出入口**
  - `缓存导出`：基于已缓存内容生成，结果写入缓存。
  - `选章直出`：所选章节实时抓取并直接导出，不写入缓存（已缓存图片只读复用；抓取失败时若有缓存副本自动回退）；设置与「缓存导出」共用。
- **排版参数**：书名、文件名、字号（`pt` / `px`）、行距、段间距（`em`）、图片宽度（`100%` / `90%` / `80%`）。
- **文本处理**：简繁转换（`不转换` / `繁体 → 简体` / `简体 → 繁体`）、首行缩进、两端对齐、每章另起一页、忽略原文样式、去除空行、目录标记有图章节。
- **字体嵌入**：字体子集化（使用 `hb-subset.wasm` 子集化引擎）；支持字体文件 URL（ttf / otf / woff2）、`下载该 URL`、`选择本地字体`、`移除字体`。
- **PDF 专属**：`加入目录页`、图片压缩（`800px` / `1000px(推荐)` / `1200px` / `不压缩`）。
- **章节选择**：`全选`、`全不选`、`取消未缓存`，并显示「已选 X/Y」。
- **排版预览**：导出前可预览实际排版效果。
- **批量操作**：选中章节可直接执行 `翻译选中`、`AI润色选中`、`重抓选中`、`删除选中`，并显示预估费用。

### 3. 内置阅读器

- **阅读模式**：`📖 双页`、`📄 单页`、`📜 滚动` 三种，可循环切换。
- **主题**：`浅色`、`护眼`、`羊皮纸`、`夜间`。
- **排版面板**：左右边距、上下边距、简繁转换、行间距、段间距、两端对齐、底栏信息开关（`时间` / `本章字数` / `全书字数` / `电量`）、图片缩进阈值（`空白≥`）、换页阈值（`缩幅≤`）。
- **字体设置**：字号（`A−` / `A＋`，14–30）、阅读字体、`系统默认字体`、`缓存字体…`、`添加本地字体文件…`、`系统字体列表…`（含搜索与翻页）。
- **顶栏功能**：`☰ 目录`、`📖 摘要`、`🔊 朗读`、`🌐 译本章`、`↩ 原文`、`💬 提问`、`🔍 查找`。
- **目录与标注**：目录弹层含 `目录` / `标注` 两个分页；标注支持 `全选`、`批量删除`（标注即书签能力的承载，可通过右键菜单或 AI 解释框添加）。
- **全文查找**：支持全书范围关键词查找并跳转定位。
- **右键菜单**：`解释选中项`、`翻译选中行(不替换原文)`、`本段编辑(翻译/手改/替换)`、`引用此段到提问(AI)`、`添加标注…`、`语境设置`（`不设置语境` / `本章` / `本页` / `选中内容上下 N 段`）、`复制选中项`、`朗读选中项`。
- **快捷键**：`Esc`（逐级关闭）、`Ctrl/Cmd+F`（全文查找）、`F`（全屏）、`H`（隐藏 / 显示栏）、`T`（目录）；分页模式下 `→` / `PageDown` / `空格` 为下一页，`←` / `PageUp` 为上一页；滚动模式下 `←` / `→` 为上一章 / 下一章；另支持滚轮翻页。
- **状态保存**：阅读进度与在线阅读记录持久保存，跨页面、跨会话继续阅读。

### 4. AI 翻译与 AI 辅助

- **服务商**：`DeepSeek`、`通义千问`、`Moonshot Kimi`、`OpenAI`、`智谱 GLM`、`Google Gemini`、`豆包(火山方舟)`、`MiniMax`、`MiniMax (CN)`、`自定义(OpenAI 兼容)`。
- **目标语言**：`简体中文`、`繁體中文`、`English`、`日本語`、`한국어`。
- **章节翻译**：`🌐 译本章` 一键整章翻译，`↩ 原文` 在原文 / 译文之间切换。
- **术语表**：`翻译自动术语`、`建议回传术语`、`术语回传上限`、`术语工具`（`自动:优先原生 tools,不支持则退回文本协议` / `仅文本协议(兼容性最好)`）。
- **提示词**：内置提示词可在设置中查看与修改（修改后会标注「已改 N」）。
- **手动润色**：逐段对照编辑，包含 `①原文译文` / `②参考译文` / `③逐词` / `④AI建议` 列显隐；支持 `查译名`、`术语表`、`原文 ↔ 译文`、`全章归一`、`全章AI润色`、`复制比对(diff)`、`回滚`、按状态过滤（`全部` / `未动` / `已改` / `通过`）。
- **多服务商交叉参考**：`各服务商译文(参考)` 可批量获取其它服务商的译文并做比对。
- **逐词解释**：点击即触发词语解释。
- **AI 综合建议**：支持填入当前段比对、填入多译文、按段数批量生成、独立设置服务商 / 模型 / 思考参数、追问历史、规则校验与 AI 核对。
- **思考模式**：`🌐 …` 支持 `标准 reasoning_effort(Gemini / OpenAI / Kimi 系)`、`Claude 式 budget_tokens`、`不发送思考参数` 三种。
- **用量与计价**：预估显示（`Token 数` / `价格(¥)`）、输入价 / 输出价 / 缓存命中输入价、余额查询、连接测试。
- **章节摘要**：`📖 摘要` 由 AI 通读本章生成 ≤120 字摘要（结果缓存，可重新生成）；`📚 摘要表` 支持全书浏览、按范围批量生成、单章重生成、清空重算。
- **AI 提问**：对话列表、`＋ 新对话`、上下文阈值、历史轮次、`允许 AI 翻书检索`、`剧透:黑幕`、工具调用、全局设置、思考开关；翻书检索可配置搜索范围（`当前章前后5章` / `全书` / `自定义`）、搜索源（`译文(优先)` / `原文` / `两者`）、搜索片段长度、结果数与排序方式、工具轮次。
- **AI 产物库**：按书保存大纲、思维导图、人物关系、时间线等产物。

### 5. OCR（图文识别）

- **入口**：面板中的 `OCR识别`（识别当前页正文）与 `预览截取`（先截取预览，确认无误再识别）。
- **本地引擎**：本地 PaddleOCR（浏览器内运行，不消耗 token）——`PP-OCRv5 mobile`（默认）、`PP-OCRv6 tiny`、`PP-OCRv6 small`；每个模型支持 `加载` / `重新加载`、`卸载`、`删缓存`，大模型额外提供 `📌 刷新后自动重载`。
- **云端引擎**：按已配置 Key 的服务商组装多模态视觉模型（Kimi / 通义 / GLM / OpenAI / Gemini / 豆包 / MiniMax）。
- **截取预览**：正文按语义段落切片（段落空行处切分，同段不拆、不切字），支持分页浏览、跳转、缩略图定位。
- **多引擎逐段对照**：所有引擎识别同一批小段并逐段比对；结果一致的自动填入，仅单引擎有结果的标蓝并自动填入，不一致的以黄底标注待人工核对。
- **核对辅助**：`⏮/⏭ 不一致` 跳转、`仅不一致` / `仅已处理` 过滤、`一键采用本引擎`、`重试空白段`、`✂ 精裁重试`、`🖼 原图重试`、`⇕ 手动拆分`、`复制全部`。
- **结果落库**：识别结果可 `存入缓存(成为普通章)`，进入统一书库并可继续翻译 / 导出。
- **标点归一化**：内置规则集（默认预设「日轻用预设」），用于一致判定与自动落库，支持 `＋ 新建` / `✕ 删除` 预设，切换即时生效。
- **站点禁用列表**：对无需 OCR 的站点自动隐藏入口并禁止下载模型。

### 6. 统一书库与缓存管理

- **统一库**：所有站点的书、章节、图片、字体、模型、子集化引擎统一存储，跨站点共用同一份书库。
- **在线阅读记录**：记录所有站点的在线阅读进度（不占用缓存空间），跨站记录会一并列出并标注归属站点。
- **书库视图**：支持搜索（书名 / 作者 / 书号）、站点筛选、阅读状态筛选（`全部阅读状态` / `未读` / `在读` / `已读完`）、来源筛选（`全部来源` / `缓存章节` / `本地 · epub` / `本地 · txt` / `本地 · mobi`），并提供 `▦ 封面墙` 视图。
- **维护操作**：`检查新章节`（比对站点新增章节并标注「有更新 +N」）、`清理孤儿数据`（清除孤儿图片与幽灵 OCR 归档）、`清空本站缓存`（唯一按站点隔离的清除操作）。
- **资源区**：统一管理字体、子集化引擎与 OCR 模型。
- **扩展弹窗**：工具栏弹窗提供 `🗂 缓存管理`、`⚙️ 设置`、`ℹ️ 版本信息`（扩展版本、统一库 · 书 / 章节 / 图片数量、已用空间）。

### 7. 本地书籍导入

- 支持导入本地 `txt` / `epub` / `mobi`（含 `.prc`），导入后与抓取书籍同等对待，可阅读、翻译、导出。
- 已知限制：带 DRM 加密的 mobi 不支持；使用 HUFF/CDIC 压缩的 mobi 不支持，需先转为 epub 或 txt。

### 8. 设置项

- **服务商**：`服务商`、`Base URL`、`模型`（`▾ 选择` / `获取模型` / 搜索）、自定义模型列表（`+ 添加模型` / `从已获取列表合并`）。
- **密钥**：`API Key`（支持 `显示` / `隐藏`）。
- **翻译**：`目标语言`、`翻译块长`、`翻译/润色 MAX TOKEN`（`2K` / `4K` / `8K` / `16K` / `32K`）、`翻译章节名`、`翻译隐晦内容`、`翻译自动术语`、`建议回传术语`、`术语回传上限`、`术语工具`、`提示词`。
- **抓取**：`抓取方式`、`图床 Referer`。
- **思考**：`思考模式`、`思考参数`。
- **计价**：`预估显示`、`输入价`、`输出价`、`缓存命中输入价`、`余额`、`连接测试`。
- **OCR**：`OCR 引擎`、`语义切分行宽阈值`、`OCR 标点归一化`、`OCR 禁用列表`。

## 三、安装

1. 下载本仓库，或下载 Release 中的 `轻小说助手-*.zip` 并解压。
2. 打开 `chrome://extensions`。
3. 开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。
5. 访问上述任一受支持站点的作品页面，页面内将出现操作面板。

运行环境要求：Chrome 109 或更高版本（Manifest V3）。

## 四、数据与隐私

- 抓取、缓存、阅读、导出、本地 OCR 均在你的浏览器本地完成，数据保存于本机（扩展存储 / IndexedDB），不经过任何第三方服务器。
- 仅当你配置了相应服务的 API Key 并主动使用 AI 翻译、AI 辅助或云端 OCR 时，相关文本或图片会按你的请求发送至你所指定的模型服务商，并受该服务商条款约束。
- 图床 Referer 白名单通过 `declarativeNetRequest` 在本地生效，用于解决防盗链，不产生外部通信。
- API Key 仅保存在本机扩展存储中，本项目不会收集或上传任何用户数据。

- `lib/` 目录下的第三方库（fflate、onnxruntime-web、eSearchOCR、OpenCC）各自遵循其原始许可。
- 部分代码由 AI 辅助编写。

## 七、目录结构

```
.
├─ manifest.json      # MV3 扩展清单
├─ sw.js              # background service worker
├─ popup.html/js      # 工具栏弹窗（缓存管理 / 设置 / 版本信息）
├─ offscreen.html/js  # 离屏文档（大批量读写书库）
├─ gm-shim.js         # GM_* API 垫片
├─ ln-store.js        # 统一书库（IndexedDB）
├─ ln-codec.js        # 编解码
├─ ln-main.js         # 主程序（面板 / 抓取 / 导出 / 阅读 / 翻译 / OCR）
└─ lib/               # 第三方依赖与本地 OCR / OpenCC
```
